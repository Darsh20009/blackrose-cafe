يحتاج Paymob Unified Checkout إلى معرّفات تكامل صالحة ضمن `payment_methods`. تُهيأ معرّفات البطاقات وApple Pay كلٌ على حدة، ومعرّفات Apple Pay المتاحة هي Live فقط. لا تعرض طريقة دفع قبل وجود معرّفها الصحيح.

بعد تأكيد الطلب، افتح بوابة الدفع مباشرة دون نقرة ثانية. في تطبيق Flutter على iOS، افتح بوابة الدفع في Safari واحتفظ بمسار الرجوع إلى التطبيق والتحقق من حالة الدفع بعد استئنافه.

**Why:** وثائق Paymob تجعل `payment_methods` حقلاً مطلوباً، والعميل طلب فتح الدفع مباشرةً مع العودة إلى التطبيق على iOS.

**How to apply:** عند تعديل أي مسار دفع، وحّد سلوك صفحة إتمام الطلب والنافذة المنبثقة، وتحقق من معرّفات التكامل قبل إنشاء نية الدفع، ثم تحقق من الدفع بعد عودة التطبيق.

لا تعتمد على طلبات GET إلى مسارات Paymob Saudi intention للتحقق من بيانات الاعتماد؛ واجهة النية ترفضها بـ405. التحقق الفعلي يتطلب إنشاء جلسة دفع، وليس فحصًا عند بدء الخادم.
**Why:** فحص القراءة أعاد `405 Method not allowed` دون أن يثبت صحة المفتاح أو خطأه.
**How to apply:** لا تنشئ نية إنتاج تلقائيًا عند الإقلاع؛ اختبر إنشاء الجلسة ضمن عملية دفع يراقبها المستخدم، وأوقف الاختبار قبل إدخال بيانات البطاقة أو تأكيدها.

مسار Paymob Acceptance للاسترداد يتطلب `Secret Key` في ترويسة `Authorization: Token ...`؛ لا تستبدله بـ`API Key` منفصل.
**Why:** مجموعة Paymob الرسمية لاسترداد/إلغاء/التقاط المدفوعات توثق هذا الترويس، بينما API Key يُرسل إلى مسارات توليد Auth Token الأخرى.
**How to apply:** احتفظ بمفتاح Secret Key مستقلًا لإتمام الدفع والاسترداد؛ لا تضف API Key لهذا المسار إلا إذا كانت وثائق Paymob لنقطة نهاية أخرى تتطلبه صراحةً.

أكد المستخدم في 2026-10-07 أن الدفع ببطاقات Paymob السعودية كان يعمل سابقاً؛ عند اختفاء الخيار، افحص التهيئة السابقة للمشروع قبل طلب معرّف جديد.
**Why:** المعرّف السابق موجود في إعداد المشروع، وفقدانه كان سبب اختفاء خيار البطاقة.
**How to apply:** استعد تهيئة البطاقة السابقة فقط لحساب Paymob السعودي المقصود، ولا تستخدم معرّفاً من حساب آخر.

استرداد طلبات Paymob الإلكترونية يجب أن يتم آليًا عبر Paymob API إلى وسيلة الدفع الأصلية، لا أن يقتصر على تسجيل محلي.
**Why:** المستخدم اختار صراحة الاسترداد التلقائي عبر API بدل المسار اليدوي.
**How to apply:** لا تسجل الاسترداد كـ«مكتمل» إلا بعد قبول Paymob؛ أبقِ الطلب قيد المعالجة إلى أن يصل تأكيد المزود.
