---
name: Unknown route handling
description: The user does not want the generic 404 page to appear for unknown app routes.
---

لا تعرض صفحة 404 العامة للمستخدم لأي مسار واجهة غير معروف؛ حوّل المسارات غير المطابقة إلى الصفحة الرئيسية.

**Why:** المستخدم طلب ألا تظهر هذه الصفحة مهما كان السبب.

**How to apply:** حافظ على مسار fallback في تطبيق الواجهة كتحويل للرئيسية لكل المسارات غير المعروفة، بما فيها مسارات الموظفين والمديرين. لا تخلط ذلك مع استجابات 404 الخاصة بواجهات API.
